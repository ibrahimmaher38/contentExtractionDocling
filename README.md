## Observations and Findings

The document `Account Closure-BRD-HDB V0.2.pdf` was processed using Docling and converted into Markdown, JSON, and HTML formats.

### Original PDF vs. Markdown

The following differences were observed between the original PDF and the generated Markdown file:

1. The **Abstract** section, which appears earlier in the original PDF, was shifted to the very end of the Markdown document alongside one of the two images.

2. The identifying information of the PDF document was extracted as a **two-column table**, with the fields `Document Title`, `Business Requirement Document` being their headers.

3. The two images in the original PDF were replaced with `<!-- image -->` placeholders in the Markdown output.

### Original PDF vs. HTML

The following differences were observed between the original PDF and the generated HTML file:

1. The **Abstract** section was shifted to the very end of the HTML document, similar to the Markdown output. However, unlike the Markdown output, the HTML document did not include image elements.

2. The **colors from the original PDF were not correctly preserved/interpreted** in the generated HTML document.
